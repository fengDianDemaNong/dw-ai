状态：设计中（产品窗口：书面 + 原型）  
产品规范：[spec/](./spec/) · 需求明细：[spec/04-requirements.md](./spec/04-requirements.md)

相对 **0.1.3**（AI 能力、提示词、知识库、逻辑表结构）：本版把「字段怎么算」和「改了谁」写成建模真源。

---

## 本版有什么

### 字段加工

- 逻辑表可声明 **0～多张来源**（别名）和 **关联**（等值键、内/左连接）。单来源时「来源表」一栏仍可用（兼容 `createdFrom`）。
- 每个字段可写 **业务口径 + 结构化加工**：透传 / 转换 / 聚合 / 派生 / 常量。五种类型在规范中心只读说明。
- **逻辑 SQL** 由定义生成：表明细同一块可切 **建表 DDL**（按方言）与 **加工 DML**（一份 INSERT SELECT）。字段抽屉给该列 SELECT 片段。都不是第二真源。
- 未写加工可以保存结构，字段标「尚未定义逻辑」；DML 用注释占位。

### 多源 DWS

- 「从 DWD 生成」可选多张 DWD，指定维度与度量（来源列 + 聚合 + 可选过滤），可加派生字段。
- 发布后写入来源、关联与字段加工。不再写死单表 `order_cnt` / `gmv`。
- ODS→DWD 发布时把脱敏/时间/空值处理落入 DWD 字段加工。

### 影响与血缘

- 保存 / 删除 / 恢复版本 / AI 采纳改已有表前，按变更分级列出下游（不拦 / 须确认 / 待复核 / 整表警告）。
- **不自动改下游**。
- 表明细展示上游、下游、**本表血缘**（表级 + 字段级）；草稿列出相对上一版的下游影响。
- 建模侧栏 **影响与血缘**：项目表级图，可下钻字段。开发中心「血缘追踪」只跳转到本页。

### 版本与发布

- 编辑 / 新建保存为**草稿**，不记版本。**发布**时生成新版本，可填备注。
- 版本对比除字段清单外，列出从 A → B 的结构变化语句（添加 / 修改 / 删除字段）。
- 恢复历史版写回为草稿，再发布才记新版本。恢复前跑影响清单。

### 沿用 0.1.3

- 自建账号、双部署模式、三套界面、授权码、AI 三项随仓建设全开
- 工作台提示词槽位、知识库、规范/建模对话带项目上下文
- 规范对象、DDL 方言视图、表版本机制、权限码（读/写/发布模型）

---

## 本版没有什么

- 指标工厂、把字段加工注册成指标
- 调度、质量巡检执行、跨项目血缘
- 任意 SQL 反解析、自动改下游表
- 按方言出三套 INSERT
- 新的 AI 槽位或新的权限码
- 平台模型目录 / 默认通道、通用后台 Chat

---

## 相对 0.1.3 的变更摘要

| 变化 | 说明 |
|---|---|
| 新增 | 表级多来源与关联；字段加工定义；逻辑 SQL（DDL + DML）由定义生成 |
| 新增 | 规范中心只读「加工类型」；字段抽屉列级 SQL |
| 改写 | DWD→DWS 多源度量向导；ODS→DWD 发布写入字段加工 |
| 新增 | 影响清单（分级）；表明细上下游与血缘；建模「影响与血缘」 |
| 改写 | 保存为草稿，发布才记版本（可备注）；版本对比给出结构变化语句 |
| 沿用 | 身份、SKU、AI 能力、提示词、知识库、规范中心 |

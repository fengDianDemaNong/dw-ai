# 智仓 0.2.0 产品需求文档

状态：已按当前可点原型定稿，进入实现窗口  
书面细则仍以 [spec/](./spec/) 为准；本篇把原型里已经点通的交互收成一份可验收需求。  
交互原型：`npm run proto -- 0.2.0` → 组织 `4234` / 仓建设 `4233` / 数据地图 `5175`

---

## 1. 产品是什么

智仓是**可组合的数据产品套件**，不是一个大单体。

| 进程 | 产品码 | 本版职责 |
|---|---|---|
| 组织平台 | `org` | 登录、租户、用户、项目、模块开通与可见范围、计算资源、服务注册、工作台外观 |
| 仓建设 | `warehouse` | 规范中心、建模中心、项目壳、数据地图入口（embed）、项目外观与设置 |
| 数据地图 | `metadata` | 独立项目 sql-lineage：检索 / 血缘 / 目录 / 临时表 / SQL 解析 / 元数据 |
| 规则引擎 | `rules` | 无用户，仓建设 REST 调用（不是 SKU） |

调度（DolphinScheduler）和数仓引擎是**租户计算资源**，不是产品 SKU，不进平台服务注册。

质量 / 服务 / 沉淀 / 开发：本版只做开通、可见范围、侧栏占位，不交付独立进程。

---

## 2. 三种运行模式

每个模块启动时选定，运行中不能改。

| 模式 | 用户 | 租户 | 谁管身份 |
|---|---|---|---|
| 独立 `standalone` | 无 | 无 | 不管人；头里的人/租户只展示 |
| 普通 `standard` | 有 | 无 | 本模块本地账号 |
| 多租户 `multi` | 有 | 有 | 组织平台是人/租户/项目真源 |

组织平台不做独立模式。套件演示走：组织 `multi` + 仓建设 `multi` + 数据地图 `standalone`/`multi`。

## 3. 角色

权限跟角色走，不做跨产品勾选矩阵。

**组织层**

| 角色 | 谁任命 | 做什么 |
|---|---|---|
| 平台用户 | 平台后台 | 开停租户、开通产品上限、服务注册、平台账号与平台外观 |
| 租户管理员 | 平台指定 | 开项目、开账号、指定项目管理员、裁模块与可见范围、计算资源、工作台外观 |
| 项目管理员 | 租户管理员 | 拉人、按已启用产品派角；各已启用产品自动映射为该产品管理角色 |
| 项目成员 | 项目管理员 | 只在被派角色且模块可见的产品里做事 |

**产品层（存在组织，模块只问）**

| 产品 | 角色 |
|---|---|
| 仓建设 | 规范管理员、建模工程师、只读 |
| 数据地图 | 目录管理员、血缘分析、只读 |
| 数据质量 | 规则管理员、巡检员、只读（本版仅派角） |
| 数据服务 | 指标管理员、服务开发、只读（本版仅派角） |

## 4. 信息架构（进入项目后）

主菜单顺序固定，租户不能拖菜单、配外链。

1. 概况  
2. 规范中心 → AI 设计规范 / 主题域 / 分层规范 / 数据等级 / 词根库 / 加工类型 / 导入导出  
3. 建模中心 → 当前项目分层 + 规范校验 + 影响与血缘  
4. 数据地图 → 全文检索 / 血缘 / 数据目录 / 临时表规则 / SQL 解析 / 元数据（iframe 去壳）  
5. 调度（仅租户已配且测通 DS 时出现）  
6. 数据质量 / 数据服务 / …（开通 ∩ 启用 ∩ 可见才出现；无在线服务则禁用）  
7. **设置**（最后一个主菜单，不是钉在屏幕最底下）→ 外观 / 项目成员 / 知识库 / 元数据服务 / 数据地图设置  

**菜单风格（项目外观里选，按组织记住）**

| 风格 | 行为 |
|---|---|
| 收起 `drawer`（默认） | 左上角汉堡弹出内容定宽高的抽屉；进入某主菜单后，左侧只留该主菜单快捷项，可用 `<` / `>` 收起 |
| 左侧 `left` | 全部主菜单常驻左侧 |
| 顶部 `top` | 全部主菜单在顶部，悬停展开子项 |

工作台「设置」与项目「设置 → 外观」都能改：**主题**（页面）和**菜单栏颜色**（只改侧栏/顶栏底色，与主题分开）。

## 6. 侧栏出现规则

`项目菜单 = 平台已开通 ∩ 租户已启用 ∩ 当前人可见 ∩ 有在线服务（否则禁用）`

- **数据地图**：分组始终出现；未开通 / 不可见 / 未派角色 → 入口禁用并说明。  
- **质量 / 服务 / 沉淀 / 开发**：看不见的整组抹掉。  
- **调度**：不是产品；租户未配或未测通 DS 则整组不出现或禁用。

---

## 7. 本版不做

- 把质量 / 服务 / 调度 / 开发做成独立可卖产品并交付完整功能  
- 租户自定义路由、配外链、通用后台 Chat  
- 用作业 SQL 覆盖字段加工；作业图写回 `logic`  
- 各产品共库或浏览器直打兄弟模块 `/api`  
- 用 Casdoor 替换组织平台（OIDC 只能挂在组织登录后）

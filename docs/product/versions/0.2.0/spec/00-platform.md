# 平台原则

产品版本 0.2.0 · 文档修订 1.3 · 状态：设计中  
相对 [0.1.4](../../0.1.4/spec/00-platform.md)：把 SKU 落成**可独立运行的产品**，组织底座只认人与开通；工种角色下放到各产品。仓建设的规范 / 建模 / 字段加工沿用 0.1.4。

**组织平台**是独立项目：租户、用户、项目、模块开通、计算资源、服务注册。单独启动，和仓建设代码隔离。后期元数据 / 质量 / 服务都复用这一套，不各自再做租户。

智仓 DW-AI 是套件中的**仓建设**产品（规范 + 建模）。组合时只认组织平台给出的 `tenant_code` + `project_code`（见 [07-context.md](./07-context.md)），不共用业务库，不用各产品本地数字 id 对外。

## 0. 每个模块三种运行模式

启动时选定，运行中不能改。详见 [06-runtime-modes.md](./06-runtime-modes.md)。

| 模式 | 配置 | 用户 | 租户 |
|---|---|---|---|
| 独立 `standalone` | 只跑本模块 | 无（请求里的人/租户只展示） | 无 |
| 普通 `standard` | 本模块自带账号 | 有 | 无 |
| 多租户 `multi` | 须独立启动组织平台，本模块登记进去 | 有（组织平台管） | 有 |

模块之间只走 REST。计算资源仍由使用方配置，不是模块进程。

## 1. 产品（SKU）

开通的是**独立产品**，不是智仓里的一组页面。套件是许可组合，不是第四个代码仓。各产品进程**不必同机**。

| 产品码 | 名称 | 本版 | 单跑 | 组合 |
|---|---|---|---|---|
| `warehouse` | 仓建设 | 本原型进程，启动后向平台注册 | 规范 + 建模 | 发布逻辑表可供给其它产品 |
| `metadata` | 数据地图 | 本机 sql-lineage `127.0.0.1:5175` | 全文检索 / 血缘 / 目录 / SQL 解析 | 项目侧栏 iframe 去壳 embed |
| `quality` | 数据质量 | 可开通；演示未注册服务 | — | 成员页可派该产品角色 |
| `serve` | 数据服务 | 可开通；星河租户内默认关闭 | — | 同上 |
| `materialize` | 沉淀优化 | 默认不开 | — | — |
| `dev` | 开发中心 | 默认不开 | — | — |

调度集群（DolphinScheduler）和数仓引擎（Hive / Spark / …）**不是**产品 SKU，是租户自己的计算资源，由租户管理员在工作台「计算资源」登记。平台服务注册不收这些。

## 2. 三层控制（产品）+ 租户计算资源

1. **平台服务注册**：产品进程启动后上报「我在哪」（基址 + 心跳），也可由平台用户手工登记。只登记建模 / 元数据 / 质量 / 服务等产品进程。
2. **平台给租户开通**：勾选该租户能用的产品上限。未开通的产品不出现在租户模块管理。数据地图分组在项目侧栏始终出现，未开通 / 不可见则禁用。
3. **租户内再裁**：租户管理员决定启用哪些已开通模块，以及**谁能看见**（仅租户管理员 / 项目管理员 / 持有该产品角色 / 全部成员）。
4. **租户计算资源**（另一条线）：DolphinScheduler 地址 + Token；后期数仓引擎连接。只存在该租户，发布后的挂任务 / 补数 / 重跑走这里。

项目侧栏 = 平台已开通 ∩ 租户已启用 ∩ 当前人可见 ∩（有在线服务则可进，否则禁用并说明）。质量 / 服务等看不见的模块从侧栏抹掉。**数据地图**本版主功能：分组始终出现，未开通或未派角色时禁用并说明。

不能任意加 URL、不能自定义路由。内容以 embed 去壳接入，由壳注入当前租户 / 项目。

## 3. 菜单

菜单仍是产品信息架构，跟版本走。租户不能拖菜单、配外链。

`multi` 组合时：组织平台（4234）管登录、租户、项目、模块、计算资源；仓建设（4233）只做规范与建模，未登录跳回组织平台。`standalone` / `standard` 不启组织平台，本模块自己出页面。

## 4. 非目标

- 把各产品合成一个 Git 仓或一个业务库。
- 租户自定义路由 / 通用后台 Chat。
- 用作业 SQL 覆盖字段加工。
- 本版不拆 `dw-model/api` / `ui` 真实现（契约见 06）。
- 本版交付质量 / 服务 / 调度 / 开发的独立进程。

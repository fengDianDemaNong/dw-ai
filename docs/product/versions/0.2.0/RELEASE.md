相对 **0.1.5**：本版是大版本调整窗口。继续定**每个模块三种运行模式**（独立 / 普通 / 多租户），并演示套件组合——产品独立、组织共用、角色按产品派。

---

## 本版有什么（原型）

- 平台「服务注册」：只登记产品进程（建模 / 元数据 / 质量 / 服务），模拟心跳与上下线
- 租户「计算资源」：自管 DolphinScheduler（地址 + Token）和数仓引擎；调度不进平台注册表
- 平台给租户开通的是产品上限，地址不写在租户上
- 租户工作台「模块管理」：启用已开通模块，并设定谁能看见
- 项目成员按已启用产品分栏派角；项目管理员自动映射各产品管理角色
- 数据地图：仓建设侧栏嵌入 sql-lineage（全文检索 / 血缘 / 数据目录 / 临时表规则 / SQL 解析 / 元数据）
- 设置：元数据服务、数据地图设置（水印 / 缩略图）
- 跨服务上下文只传 `tenant_code` / `project_code` / `user_id`（见 spec/07）
- 表明细可从设计态血缘跳到作业血缘
- 数据地图分组始终出现；未开通或未派角色则禁用。质量 / 服务仍是看不见就不出现

## 本版没有什么

- 质量 / 服务独立进程尚未拆出（契约见 spec/06）
- 把 sql-lineage 并进仓建设仓（仍是独立进程，iframe 嵌入）
- 发布自动写入对方 `meta_*`
- 数据质量 / 数据服务 / 调度 / 开发独立产品实现
- 改 0.1.4 的字段加工与影响规则

## 怎么点

1. `npm run proto -- 0.2.0` 同时起三个进程：组织平台 http://127.0.0.1:4234/ ，仓建设 http://127.0.0.1:4233/ ，数据地图 http://127.0.0.1:5175/
2. 平台 `admin` / `admin123`：服务注册只有产品进程，没有 DS
3. 张三工作台「计算资源」看本组织 DS；进项目有「调度」。启航没有 DS 则无该分组
4. 换李四：见仓建设 + 数据地图，**不见**质量（仅管理员可见）。启航默认项目也能进数据地图
5. 换王五：见数据地图分组，入口禁用（未派角色）
6. 平台用户看启航开通仓建设 + 数据地图

存储键：`dw-ai.proto.0.2.0`。

# 身份与权限

产品版本 0.1.3 · 文档修订 1.1 · 状态：设计中  
依据：[00-platform.md](./00-platform.md)

相对 [0.1.1](../../0.1.1/spec/03-identity-access.md)：本版授权码增加 **AI 能力勾选**，持码进入取 **租户仓建设许可 ∩ 授权码**。平台不单独勾选 AI。工作台用户 / 项目用右侧抽屉操作；平台进入租户**每次**输授权码；授权码可指定项目角色（不再写死只读访客）。

本篇约定账号、登录、部署模式，以及（仅多租户时）平台后台、租户用户和项目成员的边界。仓建设结论见 01 / 02，不在此改写。

## 0. 部署模式

服务启动配置（环境变量或 conf，例如 `DW_AI_MODE`）：

| 值 | 模式 | 启动后没有的东西 |
|---|---|---|
| `multi` | 多租户（默认） | — |
| `standard` | 普通 | 平台后台、选租户、租户开通 / 停用、模块按租户勾选、授权码、转让租户管理员、切换租户 |

普通模式仍有：登录、用户、项目、项目成员与角色、仓建设。工作台不出现「租户」字样。改配置必须重启服务。

普通模式 **AI 三项默认全开**，不做第二套 SKU，界面不出现「本组织未开通此项」。工作台可关大模型通道与改提示词，那不是平台许可。

原型用 `VITE_DEPLOY_MODE` 或地址 `?mode=standard` / `?mode=multi` 模拟启动。

## 1. 登录

**普通模式**：只需用户名 + 密码，通过后直达项目列表。没有选租户，没有平台后台。平台账号不能登录。

**多租户**：两步，缺一不可。

1. **认人**：用户名 + 密码。错了只提示「用户名或密码错误」，不暗示哪一项错。停用账号不能登录。
2. **进租户**：列出该用户所属且未停用的租户。
   - 只有一个 → 租户管理员进工作台；其他人进已加入的项目（概况）。未加入任何项目则提示联系管理员。
   - 多个 → 停在选择页，点一个再按上面规则进入。
   - 平台用户登录后直接进平台后台（侧栏：租户管理、平台用户、外观与布局）。进某个租户必须先有该租户的授权码；授权后按该租户角色落点（不是租户管理员则进项目，不进工作台）。

未登录不能进工作台、项目、用户管理。已登录但未选租户，不能进 `/projects`、项目内页。退出后回到登录第一屏。普通成员即使拼 `/projects` 也会被送到项目或「未加入项目」页。

工作台不再提供「新建租户」。切换租户回到选择页，不退出账号。

## 2. 角色

权限跟角色走，不做任意勾选的权限矩阵。

**普通模式**只有项目侧角色，外加一名（或若干）能建项目、管用户的管理员，不叫租户管理员，也不出现平台用户。

**多租户**如下。

| 角色 | 谁任命 | 能做什么 |
|---|---|---|
| 平台用户 | 平台后台新增 | 开停租户、勾选模块、指定该租户第一位管理员、管理其它平台用户（新建、改密码、停用）。**不能**直接进租户页面。仓建设开通则三项 AI 自动全开，平台不单独勾选。 |
| 租户管理员 | 平台指定第一位；之后由现任转让 | **新建项目**并指定项目管理员；本租户用户：新建、编辑（抽屉内改资料 / 项目角色 / 停用）、删除（移出本组织）、重置密码、指定项目管理员；生成 / 编辑 / 停用 / 删除平台授权码（功能范围、项目与角色、AI 能力）；**把管理员权限转让给本租户另一人**（自己降为普通成员）。 |
| 项目管理员 | 租户管理员指定 | 拉项目成员并派角色；**规范中心可新增 / 修改 / 删除**；建模中心读写发布。 |
| 建模工程师 | 本项目管理员指定 | 规范中心**只能查看**（可走规范问答）；建模中心可作业。 |
| 只读访客 | 本项目管理员指定 | 规范与建模均只读（可走规范问答）。 |

同一人可以在 A 租户当管理员、在 B 租户当普通成员；平台用户一般不属于任何租户。

平台用户只有在输入该租户未作废、未过期的授权码之后，才能进入该租户页面做验收 / 协助。每次点「进入」都要当场输码；没有有效码不能进工作台。

## 3. 平台后台（仅多租户）

普通模式不部署、不出现此后台。

入口只给平台用户，路径独立于租户工作台。侧栏分组：

- **平台管理**：租户管理、平台用户
- **系统设置**：外观与布局（主题、菜单在左侧或顶部）。**只作用于平台管理后台**，不会带到租户工作台或项目。

**租户：**

- 看到全部租户（含已停用）。
- **创建租户**：编码、名称、开通模块、指定已有账号或当场新建该租户管理员。创建后带一个空的默认项目。勾选仓建设则三项 AI 自动全开，页上不出现 AI 能力勾选。
- **停用 / 启用**租户。
- **编辑租户**：可改名称、开通功能（未上线模块标「未上线」）、指定已有账号为该租户管理员。不提供 AI 能力勾选。
- **进入租户**：每次点「进入」都须输入该租户的授权码，不因上次已绑定而跳过。码无效则不能进工作台。

**平台用户：**

- 列表、新建平台账号（用户名全局唯一 + 初始密码）。
- 修改密码、停用 / 启用。不能停用自己，也不能停用最后一个可用的平台用户。

不能做：在后台编辑数仓规范或模型；无授权进入租户页面。

## 3.1 平台授权码（仅多租户）

租户管理员在「用户管理」生成。平台用户凭码进入该租户。生成时须指定：

- **有效期**：永久，或用日历选到期时间（到期自动失效）。
- **功能范围**：开通哪些功能（仓建设 / 数据服务等，且不能超出该租户已开通模块）。不勾选则表示该侧不限制。
- **项目与角色**：全部项目用同一角色，或按项目勾选并指定角色（项目管理员 / 建模工程师 / 只读访客）。不再写死只读访客。不能进工作台、不能转让管理员。
- **AI 能力**（本版）：勾选 `spec_design` / `spec_ask` / `model_design`。空 = 不限制。持码进入后有效能力 = **租户仓建设许可 ∩ 本码勾选**。未开仓建设则三项皆无；不能靠授权码放出仓建设未开时的能力。

同一授权码在有效期内可供平台用户使用；作废或过期后已绑定的进入资格一并失效。租户管理员随时作废。

无能力时：项目内「AI 设计规范」、各层「AI 设计」入口可见但禁用，说明「本组织未开通此项」。

## 3.2 转让租户管理员（仅多租户）

现任租户管理员把自己的管理员权限交给本租户另一名**未停用**用户：对方升为管理员，自己降为普通成员。转让后自己不再能生成授权码、开项目、管用户，除非新管理员再转回来。

平台用户即使持有授权码，也不能代替转让。

## 4. 用户

入口在进项目之前的租户工作台 **系统管理**（用户管理、角色管理、项目管理、知识库、设置），仅租户管理员可见。设置改**本租户**工作台和项目的主题、菜单位置，以及**本租户大模型**与 **AI 提示词**，与平台管理后台互不影响。进项目后侧栏不再出现系统管理；左下角（顶部菜单时在右上角）个人信息可改资料、改密码、切换租户。**「返回工作台」只给租户管理员。**

管理员可以：

- 看到本租户用户列表（显示名、用户名、租户角色、账号状态、所在项目）。行上只有 **编辑 / 删除**。
- **新建**：新账号（用户名全局唯一 + 初始密码）或把已有账号拉进本租户。
- **编辑（右侧抽屉）**：改显示名、用户名、租户角色、状态；加入 / 改角色 / 移出项目，点保存一并写入。指定项目管理员、重置密码在抽屉内即时生效。不能停用自己。
- **删除**：从本组织移除（账号仍在，可再拉入）。不能删除自己。
- **项目管理**：块 / 行切换。卡片或行上只有 **进入项目** 与 **编辑**。名称、编码、说明、管理员、状态、删除在编辑抽屉里。停用后不能进入；切换项目下拉不列出已停用项。

普通成员只看到自己被派进的项目。未派进的人进不了该项目。日常拉人和改角色在项目内「项目成员」，由项目管理员做。无成员管理权限不能改角色；顶栏展示当前项目角色。

## 5. 与项目成员的边界

| | 租户管理员 | 项目管理员 |
|---|---|---|
| 管什么 | 开项目、开账号、指定**谁是该项目的管理员** | 把已有租户用户拉进**本项目**，并给角色 |
| 在哪管 | 系统管理「项目管理」「用户管理」 | 项目内「项目成员」 |
| 拉人从哪来 | 产品账号库（新建或已有账号） | **本租户用户**，不能填系统外的名字 |

项目不负责开账号。没有租户身份，不能出现在项目成员里。租户管理员不代替项目管理员去派建模 / 只读。

## 5.1 角色与 AI 能力如何叠

能力开通决定「能不能用这项」；角色决定「能不能写」。两者同时满足才允许同步 / 写入。

| 动作 | 需要的能力 | 需要的权限 |
|---|---|---|
| 打开规范设计对话并同步草案 | `spec_design` | `spec:write`（仅项目管理员） |
| 规范问答（只出文字） | `spec_ask` | `spec:read` |
| 打开建模 AI 并写入 / 记版本 | `model_design` | `model:write` |
| 只看建模草案、不写入 | `model_design` | `model:read` |

仅开通 `spec_ask`、或有 `spec_design` 但无 `spec:write`：走问答槽，右侧不出现可同步草案（或草案区只读）。  
有 `spec_design` 但无能力勾选：入口禁用。  
有写入权限但租户 / 授权码未开对应能力：同样禁用，不能靠拼 URL 提交。

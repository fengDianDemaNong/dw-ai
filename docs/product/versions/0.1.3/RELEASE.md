## 本版有什么

### AI 能力（仓建设之下）

- 三项能力，不替代模块勾选；未开通仓建设则无效：
  - `spec_design`：规范设计（对话 + 勾选同步）
  - `spec_ask`：规范问答（只读，不写库）
  - `model_design`：分层建模 AI（对话 + 勾选写入 / 记版本）
- **平台**开租户 / 编辑租户：在「开通功能」旁勾选 AI 能力。默认：仓建设开通则三项全开。
- **授权码**：同样勾选。空 = 不限制（与模块空=全部一致）。持码进入后取 **租户开通 ∩ 授权码**。生成 / 编辑时可指定**项目与角色**（全部项目同一角色，或按项目勾选），不再写死只读访客。
- **角色仍约束写入**：`spec_design` 须 `spec:write` 才能同步；`spec_ask` 有 `spec:read` 即可；`model_design` 写入须 `model:write`。
- 无能力时入口可见但禁用，文案「本组织未开通此项」。
- **普通模式**：三项默认全开，不做第二套 SKU，不出现「未开通」。

### 工作台提示词

- 设置页在大模型下方增加 **AI 提示词**，按槽位存，产品内置一套中文默认：
  - `spec.system` / `spec.ask.system` / `model.system`
- 管理员可改；「恢复默认」。占位符由服务端替换：`{{project}}` `{{domains}}` `{{layers}}` `{{roots}}` `{{grades}}` `{{layer}}` `{{focus_table}}`。
- 未开大模型：仍走内置草案，**不读租户槽位**；页上提示「先启用大模型，提示词才会用于代发」。
- 密钥仍加密不回传；提示词明文回给租户管理员。

### 仓建设 AI 加深

- **规范设计**：代发附带当前项目主题域 / 分层 / 等级 / 词根摘要；默认增量补全；覆盖须勾选「覆盖已有编码」；草案尽量带一句理由。
- **规范问答**：无 `spec:write` 或仅开通 `spec_ask` 时走问答槽，只出文字，右侧不出现可同步草案（或只读）。
- **建模 AI**：代发带本层规则、已有表名、主题域编码；改表时带当前字段。页上标明「已带本项目规范」。`model:write` 才能写入。
- 代发失败：提示后回退内置草案。ODS→DWD / DWD→DWS 发布前继续跑规范校验，失败信息可读。

### 工作台与平台交互（相对 0.1.1 书面）

- 平台进入租户**每次**输授权码，不因已绑定跳过。编辑租户可改名称、未上线模块标记、AI 能力。
- 工作台用户 / 项目：行上编辑 + 删除（项目删除在编辑抽屉）；指定管理员、重置密码在用户抽屉内即时生效。
- 项目支持块 / 行；停用后不能进入。
- **知识库**：工作台按项目勾选 Hive / Spark / ClickHouse / Doris；本版先提供各引擎建表、改表、分区操作手册。租户可按 JSON / Markdown 模版导入补充篇。项目内只读已开通引擎。

### 沿用 0.1.1 / 0.1.2

- 自建账号、双部署模式、三套界面、授权码、转让管理员
- 规范中心对象与建模 ODS/DWD/DWS/校验/DDL/表版本
- 多库底座与手动 seed（发布形态仍以 0.1.2 为准）

---

## 本版没有什么

- 平台模型目录 / 默认通道
- 租户自定义任意路由、通用后台 Chat
- 开发中心 / 质量 / 指标 AI
- 提示词按项目分叉（本版只按租户）
- 登录页自助开租户、权限勾选矩阵、以 Casdoor 为主路径

## 相对 0.1.1 的变更摘要

| 变化 | 说明 |
|---|---|
| 新增 | 仓建设下三项 AI 能力；平台开通与授权码勾选；入口禁用文案 |
| 新增 | 工作台提示词槽位、占位符、恢复默认 |
| 加深 | 规范设计 / 问答分流；对话带本项目规范摘要；建模页标明已带规范 |
| 新增 | 工作台 / 项目知识库：按引擎手册（Hive / Spark / ClickHouse / Doris），按项目开通；可按模版导入 |
| 改写 | 进入租户每次输码；授权码指定项目角色；用户/项目抽屉操作 |
| 沿用 | 身份、三套壳、模块 SKU、规范对象、建模版本与生成路径 |

# 智仓 0.1.5 Release 功能清单

状态：设计中（产品窗口：书面 + 原型）  
产品规范：[spec/](./spec/) · 需求明细：[spec/04-requirements.md](./spec/04-requirements.md)

相对 **0.1.4**（字段加工、影响面）：本版定**每个模块三种运行模式**（独立 / 普通 / 多租户），并演示套件组合——产品独立、组织共用、角色按产品派。

---

## 本版有什么（原型）

- 平台「服务注册」：只登记产品进程（建模 / 元数据 / 质量 / 服务），模拟心跳与上下线
- 租户「计算资源」：自管 DolphinScheduler（地址 + Token）和数仓引擎；调度不进平台注册表
- 平台给租户开通的是产品上限，地址不写在租户上
- 租户工作台「模块管理」：启用已开通模块，并设定谁能看见
- 项目成员按已启用产品分栏派角；项目管理员自动映射各产品管理角色
- 元数据 embed 页：目录、作业血缘、SQL 解析、数据目录、临时表规则
- 表明细可从设计态血缘跳到作业血缘
- 未开通 / 本组织关闭 / 当前人不可见：侧栏不出现；无在线服务或未派角色：入口禁用并说明

## 本版没有什么

- 把 `ui/` / `services/api` 按三模式真正拆仓（契约见 spec/06）
- 真的反代 sql-lineage 进程或真实心跳
- 发布自动写入对方 `meta_*`
- 数据质量 / 数据服务 / 调度 / 开发独立产品实现
- 改 0.1.4 的字段加工与影响规则

## 怎么点

1. `npm run proto -- 0.1.5` 同时起两个进程：组织平台 http://127.0.0.1:4224/ ，仓建设 http://127.0.0.1:4223/
2. 平台 `admin` / `admin123`：服务注册只有产品进程，没有 DS
3. 张三工作台「计算资源」看本组织 DS；进项目有「调度」。启航没有 DS 则无该分组
4. 换李四：见仓建设 + 元数据，**不见**质量（仅管理员可见）
5. 换王五：只见仓建设，**看不见**元数据
6. 平台用户看启航仅开通仓建设

存储键：`dw-ai.proto.0.1.5`。

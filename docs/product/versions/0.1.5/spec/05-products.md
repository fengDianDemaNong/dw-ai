# 独立产品与组合

产品版本 0.1.5 · 文档修订 1.2 · 状态：设计中

## 1. 单跑与组合

每个产品自己的库、安装包、前端。每个模块三种启动模式见 [06-runtime-modes.md](./06-runtime-modes.md)。

**组织平台**只在 `multi`（以及组织自己的 `standard`）时启动，不和仓建设混仓。其它模块后期都接这一套，不再自建租户。

- 独立：本模块无登录。
- 普通：本模块自己登录，无租户。
- 多租户：仓建设不兼登录，验组织平台给出的 `tenant_id` + `project_id`（各模块项目 ID 必须相同）。

跨产品只认：`tenant_code` + `project_code`，以及数据对象 `catalog.schema.table`。一个组织项目 = 一座仓 = 一份物理目录；多集群用元数据里的数据目录，不再拆项目。

`multi` 下产品进程启动后须向**平台服务注册表**报告自己的基址。独立 / 普通不登记。平台不假设建模与元数据在同一台机器。

## 2. 元数据接入（本版可点）

星河演示：平台已登记 `http://192.168.10.21:8080`（心跳，在线）。项目侧栏「元数据」为对方 embed 页（仅对可见范围内的人出现）：

- 元数据目录：物理名，标记是否已有逻辑表
- 作业血缘：SQL 解析图，可从表明细「设计态血缘」跳入
- SQL 解析：血缘分析可解析；保存需血缘分析或目录管理员
- 数据目录 / 临时表规则：仅目录管理员（项目管理员自动具备）

设计态血缘仍在建模中心，来自 `sources` / 字段加工。作业图不得写回 `logic`。

## 3. 事件（书面，原型不发真实请求）

- 仓建设发布 → 可写入元数据目录（本版不自动写，只在目录上标「已绑逻辑表」）
- 元数据保存作业血缘 → 建模影响面可增加「作业下游」栏（本版用跳转代替）
- 产品进程心跳 → 更新平台注册表的地址与在线状态

## 4. 质量 / 服务

平台可开通，租户可再关。无在线产品服务时，对可见的人：侧栏禁用并说明「平台没有该产品的在线服务」。不要在仓建设 `ui` 里实现这些页面当正式功能。

## 5. 计算资源（租户自管，不是产品）

调度用租户自己的 DolphinScheduler：租户管理员在工作台「计算资源」填 API 基址和 Token（Token 在 DS 安全中心生成）。平台不登记这套集群。发布模型后的挂载、补数、重跑只打本组织这条 DS。

数仓引擎（Hive / Spark / ClickHouse / Doris）同样是租户后期自己配的连接，不进平台服务注册。项目上勾选的引擎知识库，和这里的连接不是一回事。

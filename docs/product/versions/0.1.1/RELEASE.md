## 本版有什么

### 部署

- 两种启动模式（改配置须重启）：**多租户** / **普通**（无平台、无租户字样，仍有用户/项目/仓建设）

### 身份

- 产品自建账号：登录、停用、重置密码、改自己的资料和密码
- 多租户：一人可属多个租户；先登录再选租户；平台用户凭租户授权码进入（日历选到期，可限定功能与项目）
- 角色：平台用户、租户管理员、项目管理员、建模工程师、只读访客（权限跟角色走）

### 三套界面

| 界面 | 谁进 | 做什么 |
|---|---|---|
| 平台管理 | 平台用户 | 开停租户、勾模块、管平台账号、平台外观 |
| 工作台 | 仅租户管理员 | 用户、角色说明、项目、本租户外观与大模型、授权码、转让管理员 |
| 项目 | 项目成员 | 概况、规范、建模；侧栏不再出现系统管理 |

普通成员登录后直接进已加入的项目，看不到工作台，个人信息无「返回工作台」。

### 仓建设（项目内）

- **规范中心**（沿用 0.1.0）：AI 设计规范、主题域、分层、等级、词根、导入导出。**只有项目管理员能写规范**
- **建模中心**（0.1.0 + 本版）：分层总览/表/DDL、ODS→DWD、DWD→DWS、规范校验；**每层 AI 设计表**；**模型版本**（历史、对比、恢复并再记一版）

### 外观与大模型

- 平台外观与租户外观互相独立；工作台与项目共用该租户外观
- 大模型只在租户设置里配；未开启时 AI 对话用内置草案

### 项目壳

- 概况；多于 1 个可进项目时顶栏右侧显示切换（无「项目」前缀）
- 项目成员由项目管理员从本租户用户拉人

---

## 本版没有什么

- 开发中心、沉淀优化、数据服务（指标工厂/市场/网关）——原型可点，**不作为本版上线范围**
- 登录页自助开租户、租户自定义菜单/路由、权限勾选矩阵
- 以 Casdoor 等外部登录作为本版主路径

---

## 相对 0.1.0 的变更摘要

| 变化 | 说明 |
|---|---|
| 新增 | 自建账号、双模式、平台后台、工作台、授权码、转让管理员 |
| 新增 | 租户大模型配置；每层建模 AI；逻辑表版本 |
| 收口 | 规范写入仅项目管理员；工作台仅租户管理员 |
| 沿用 | 规范对象与建模 ODS/DWD/DWS/校验/DDL |

# 0.1.1 功能需求清单

产品版本 0.1.1 · 文档修订 1.0 · 状态：设计中  
依据：[00-platform.md](./00-platform.md)、[01-spec-center.md](./01-spec-center.md)、[02-modeling-center.md](./02-modeling-center.md)、[03-identity-access.md](./03-identity-access.md)

本篇把已确认的产品能力拆成**可验收条目**。模式列：`multi` 仅多租户；`standard` 仅普通模式；`both` 两种都要。角色列为空表示所有已登录且有入口权限的人。

交互原型：`npm run proto -- 0.1.1` → http://127.0.0.1:4183/  
Release 摘要：[../RELEASE.md](../RELEASE.md)  
实现拆分：`docs/tech/0.1.1-checklist.md`

## 0. 交付边界

**本版交付：** 自建账号；双部署模式；三套界面（平台管理 / 租户工作台 / 项目）；仓建设（规范中心 + 建模中心，含每层 AI 设计与模型版本）；租户大模型配置。

**本版不交付（原型侧栏可点，仅占位）：** 开发中心、沉淀优化、数据服务（指标目录 / 工厂 / 网关 / 市场）。

**相对 0.1.0：** 仓建设结论基本沿用；本版增量是身份、三套壳、外观与大模型隔离、规范写权限收口、建模 AI 与版本。

## 1. 部署与登录

| # | 需求 | 模式 | 角色 | 验收要点 |
|---|---|---|---|---|
| 1.1 | 启动配置二选一：`multi` / `standard`，运行中不能改，改须重启 | both | — | 普通模式无平台后台、无选租户、无授权码、无转让管理员、界面不出现「租户」字样 |
| 1.2 | 用户名 + 密码登录；错误只提示「用户名或密码错误」 | both | — | 不暗示哪一项错 |
| 1.3 | 停用账号不能登录 | both | — | — |
| 1.4 | 普通模式：登录后按管理员进工作台、其他人进已加入项目 | standard | — | 无平台账号登录；无选租户页 |
| 1.5 | 多租户：先认人再进租户；仅一个可用租户则自动进入 | multi | — | 多个则停在选择页 |
| 1.6 | 登录后落点：租户管理员 → 工作台；其他人 → 已加入项目概况；未加入任何项目 → 提示页 | both | — | 拼 `/projects` 的普通成员不能进工作台 |
| 1.7 | 平台用户登录后进平台后台，不能直接进租户 | multi | 平台用户 | 进租户必须有效授权码 |
| 1.8 | 未登录不能进工作台、项目、用户管理；已登录未选租户不能进项目内页 | multi | — | 退出回到登录第一屏 |
| 1.9 | 切换租户不退出账号，回到选择页再进 | multi | 多租户用户 | — |

## 2. 平台管理（仅 multi）

| # | 需求 | 角色 | 验收要点 |
|---|---|---|---|
| 2.1 | 独立路径 `/admin`，侧栏「平台管理」：租户、平台用户、设置 | 平台用户 | 普通模式不出现 |
| 2.2 | 租户列表含已停用；创建（编码、名称、模块、指定或新建管理员）；创建后带空默认项目 | 平台用户 | 登录页不能自助开租户 |
| 2.3 | 停用 / 启用租户；改模块；指定或新建该租户管理员 | 平台用户 | — |
| 2.4 | 「进入」租户须有效授权码（或仍有效的绑定） | 平台用户 | 无码只能管开通，不能进工作台/项目 |
| 2.5 | 平台用户：列表、新建（用户名全局唯一 + 初始密码）、改密码、停用/启用 | 平台用户 | 不能停用自己；不能停用最后一个可用平台用户 |
| 2.6 | 平台设置：主题、菜单位置，**只作用于平台后台** | 平台用户 | 进入租户后外观仍是该租户的，不带平台主题走 |

平台后台不能编辑数仓规范或模型。

## 3. 租户工作台（系统管理）

仅**租户管理员**（普通模式为能建项目/管用户的管理员）可见。其他人看不到入口，个人信息无「返回工作台」。

| # | 需求 | 模式 | 验收要点 |
|---|---|---|---|
| 3.1 | 主菜单「系统管理」：用户管理、角色管理、项目管理、设置 | both | 进项目后侧栏不再出现系统管理 |
| 3.2 | 用户：本租户列表；新建账号或拉已有账号进租户；停用/启用；删除（移出本组织）；重置密码；指定某项目的项目管理员 | both | 不在这里派建模/只读；不能删除自己 / 最后一名管理员 |
| 3.3 | 角色：展示租户角色与项目角色边界（说明页即可，不做勾选矩阵） | both | 权限跟角色走 |
| 3.4 | 项目：管理员新建并指定项目管理员、删除项目；可选导入通用规范模板；块/行切换显示；成员只看到自己加入的项目 | both | 未加入的项目不出现在普通成员列表 |
| 3.5 | 设置：主题、菜单位置，作用于**本租户工作台和项目**，与平台互不影响；不同租户各记一份 | both | 默认菜单在左侧 |
| 3.6 | 设置：大模型（启用、服务商、接口地址、密钥、模型名），按租户隔离 | both | 平台设置无此项；未开启时对话用内置草案 |
| 3.7 | 生成 / 作废 / 删除平台授权码：日历选到期（或永久）；勾选功能与项目范围 | multi | 作废或删除后已绑定进入资格失效；平台用户只能进范围内项目与模块 |
| 3.8 | 转让租户管理员给本租户另一未停用用户；自己降为普通成员 | multi | 平台用户持码也不能代为转让 |

## 4. 项目壳与概况

| # | 需求 | 角色 | 验收要点 |
|---|---|---|---|
| 4.1 | 进项目后侧栏为产品目录 ∩ 已开通模块 ∩ 当前项目角色 | 项目成员 | 租户不能改菜单路径 |
| 4.2 | 概况页：项目摘要与建议下一步 | 项目成员 | 顶栏右侧：可进项目多于 1 个才显示切换下拉，无「项目」二字前缀 |
| 4.3 | 概况及其他项目页顶栏：租户管理员可点租户名回工作台 | 租户管理员 | 其他人顶栏租户名不可点回工作台 |
| 4.4 | 项目成员：项目管理员从**本租户用户**拉人并派角色（admin / modeler / viewer） | 项目管理员 | 不能填系统外名字；开账号回工作台用户管理 |
| 4.5 | 分层入口随本项目已配置分层变化 | 项目成员 | 未配置的层不出现 |

## 5. 规范中心

沿用 0.1.0 页面职责，本版权限收口如下。

| # | 需求 | 角色 | 验收要点 |
|---|---|---|---|
| 5.1 | AI 设计规范：对话生成主题域/分层/等级/词根草案，勾选后同步 | 写规范=项目管理员 | 其他人只读对话结果，不能同步 |
| 5.2 | 主题域 / 分层 / 数据等级 / 词根：增删改；分层可自定义 | 同上 | 删除被表引用则禁止 |
| 5.3 | 导入导出整包规范（不含表）；套用等级模板 | 写规范才能导入/套模板 | 导出只读角色可用 |
| 5.4 | 新建项目可选「导入通用规范模板」 | 租户管理员 | 空项目不预置演示业务表 |
| 5.5 | 建模工程师、只读访客：规范中心只能查看（含导出） | modeler / viewer | 入口、按钮、提交一致拒绝写入 |

## 6. 建模中心

沿用 0.1.0 逻辑表、DDL、ODS→DWD、DWD→DWS、规范校验；本版新增 AI 设计与版本。

| # | 需求 | 角色 | 验收要点 |
|---|---|---|---|
| 6.1 | 各层总览 / 列表 / 详情；手建改删表 | 写模型=项目管理员或建模工程师 | 表名项目内唯一；已下线不作为生成首选 |
| 6.2 | 每层 **AI 设计**：对话设计新表或改已有表；勾选后写入 | 写模型才能写入 | 新建为草稿；改已有表记新版本；无写权限只能看草案 |
| 6.3 | 表明细 **AI 改这张表** | 同上 | 对话只针对当前层 |
| 6.4 | 模型版本：每次结构变更记一版（新建/编辑/AI 采纳/恢复）；无变更不记 | 读模型可看历史与对比 | — |
| 6.5 | 版本对比、查看某版快照、把历史版切换为当前（再记一版「从 vN 恢复」） | 切换须写模型 | 历史不删、不改写；当前表=最新一版 |
| 6.6 | 从 ODS 生成 DWD、从 DWD 生成 DWS；规范错误不可发布 | 写模型发起；发布须发布权限 | 与 0.1.0 一致 |
| 6.7 | 规范校验页对已有表做命名与词根检查，只读 | 读模型 | — |
| 6.8 | DDL 为逻辑表视图，可切 Hive / Doris / MySQL | 读模型 | 不出现用户可选存储格式 |

## 8. 非目标

与 [00-platform.md](./00-platform.md) 第 5 节一致，本版不做：

- 登录页自助新建租户，或把项目提升成租户
- 租户拖菜单、配外链、自定义路由
- 用通用后台脚手架替换本产品信息架构
- 任意勾选的权限矩阵
- 本版生产交付开发中心、沉淀优化、数据服务
- 以 Casdoor 等外部 IdP 作为本版登录主路径（产品自建账号）

# 规范中心

产品版本 0.1.1 · 文档修订 1.0 · 状态：已冻结  
依据：[00-platform.md](./00-platform.md)

规范中心维护**当前项目**的约定：主题域、分层、词根、数据等级，以及导入导出。  
约定被建模、生成草案、对外访问共同遵守。规范中心不建仓表。

## 1. 页面职责

| 入口 | 职责 |
|---|---|
| AI 设计规范 | 按行业或描述生成提案（主题域、分层、词根、等级）；必须人工采纳后才写入 |
| 主题域 | 增删改主题域 |
| 分层规范 | 增删改分层及本层策略；允许自定义分层（如 DIM、STG） |
| 数据等级 | 增删改等级；可套模板 |
| 词根库 | 增删改词根，供命名识别与校验 |
| 导入导出 | 导出/导入整包规范，不含表数据 |

新建项目时可选择「导入通用规范模板」。空项目不预置演示业务表。

## 2. 主题域

每个项目内编码唯一。字段包括：编码、名称、业务定义、业务/技术/数据负责人、关联域、核心实体。

表归属主题域；命名中的主题域段引用编码。删除前须无表引用，或先迁移归属。

## 3. 分层规范

分层编码为开放字符串，不限于 ODS / DWD / DWS / ADS。

每层可配置：

| 项 | 含义 |
|---|---|
| 命名说明 | 本层表名如何写 |
| 保留策略 | 生命周期说明 |
| 对外服务 | 禁止 / 需审批 / 允许。参与访问裁决，不阻止建表 |
| 字段格式 | 字段命名与格式约定 |
| 时间格式 | 日期、时间戳格式 |
| 脱敏 | 保持原文 / 掩码 / 哈希 / 加密 / 禁止下沉 |
| 空值 | 保留 / 默认填充 / 空值打回，及填充说明 |

项目未写全时，用产品内置的层默认（可改）：

- ODS：可明文，空值保留
- DWD：敏感须脱敏后入明细
- DWS：不得保留可识别个人身份的字段（禁止下沉）
- ADS：对外前按应用再处理

侧栏建模分组的分层顺序与本项目分层配置一致。  
删除分层前：该层不能再有表。

## 4. 数据等级

等级是项目内编码（模板可用 L1–L4，但产品不把四级写死为唯一体系）。

每级包括：编码、名称、排序、颜色、查询策略、导出策略、要求说明、适用示例。

查询：可直接查 / 登录后可查 / 审批后可查 / 禁止查询。  
导出：可导出 / 审批后导出 / 禁止导出。

表可设等级；字段可设等级，空则继承表。  
有效等级用于：访问裁决、建表与 DDL 注释中的安全信息。

内置模板：通用四级、通用三级、广告四级。套用时可覆盖或合并；编码冲突须明确提示。

被表或字段引用的等级编码不可删，只可改策略与说明。

## 5. 词根

词根分业务、技术、时间三类。用于字段识别、建议名、命名校验。  
无法匹配词根时默认告警，不阻断发布（除非项目日后将命名设为强制——首期非强制）。

## 6. AI 提案

输出可含：主题域、分层、词根、等级、命名说明。  
采纳前必须人工确认。采纳只写规范，不自动建表。

## 7. 导入导出

导出包标识为产品格式版本（实现层规定文件头）。内容仅四类规范及来源租户/项目名称，**不含表、草案、作业**。

导入在当前项目内按编码合并。正在被表引用的分层编码、等级编码不可从导入中删除。

## 8. 规范如何约束下游（产品语义）

| 规范 | 约束 |
|---|---|
| 主题域 | 表归属、命名中的域、生成时的归域 |
| 分层列表 | 合法分层、侧栏、缺省脱敏/空值 |
| 脱敏 / 空值 | 生成明细或汇总草案时的转换与拦截 |
| 对外服务 | 查询与服务是否允许或要审批 |
| 数据等级 | 表/字段可选值、注释、访问严度 |
| 词根与命名 | 校验与建议名 |

访问裁决取「分层对外服务」与「表/字段有效等级」中更严的一方。禁止严于审批，审批严于登录，登录严于允许。

## 9. 权限（产品语义）

- 看规范、导出：需要「读规范」（项目管理员、建模工程师、只读访客）
- 改规范、导入、套模板、采纳提案：需要「写规范」，**仅项目管理员**。建模人员不能改规范。

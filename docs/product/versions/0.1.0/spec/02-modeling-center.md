# 建模中心

产品版本 0.1.0 · 文档修订 1.0 · 状态：已冻结  
依据：[00-platform.md](./00-platform.md)、[01-spec-center.md](./01-spec-center.md)

建模中心管理**逻辑表**，并按规范生成、审核从源层到明细、从明细到汇总的草案。  
不管理指标定义，不指定物理存储格式。

## 1. 导航与页面

| 入口 | 职责 |
|---|---|
| 各分层（动态） | 按主题域看总览、表列表、表明细 |
| 规范校验 | 对已有表做命名与字段约定检查，不改表 |
| 从 ODS 生成 | 由 ODS 生成 DWD 草案并审核 |
| 从 DWD 生成 | 由 DWD 生成 DWS 草案并审核 |

分层入口来自本项目分层规范。未配置的层不出现。  
自定义分层（如 DIM）与内置层共用同一套总览 / 列表 / 详情，不各写一套产品。

当前产品只提供两条智能生成路径：ODS → DWD、DWD → DWS。其他层先手建表。

未归属主题域的表归在「未归属」。

## 2. 逻辑表

表描述业务结构，不描述落在哪种文件格式或哪套引擎上。

**表：** 表名、中文说明、分层、主题域、粒度、周期、分区、状态（草稿 / 已发布 / 已下线）、数据等级、来源表（若由生成产生）。

**字段：** 字段名、逻辑类型、注释、是否不为空、默认值、是否敏感、字段等级、枚举值（可选）。

逻辑类型为跨引擎名称，例如字符串、整数、高精度小数、布尔、日期时间。  
**不为空**勾选后才能设默认值；默认值随建表语句写出。

建表界面不出现「存储 / ORC」一类引擎细节。

状态：草稿可改；已发布可改结构（首期不强制版本表）；已下线不可再作为生成目标的首选（列表仍可见）。

## 3. 建表语句（DDL）

DDL 是逻辑表的**视图**，不是第二种真源。同一张表可按目标引擎查看：

- Hive
- Doris
- MySQL

产品要求：

- 不在语句中指定用户可选的存储格式。
- 用户填写的安全信息写入注释：表级含等级及查询/导出策略、主题域、粒度（仅已填项）；字段级含等级、敏感标记。字段未单独设等级则继承表等级。
- 不为空且已填默认值时，语句中带默认值。
- 建表过程中即可预览，方言可切换。

加工/插入用的参考 SQL 首期保持一份，不按方言拆成三套。

## 4. ODS → DWD

1. 选择一张 ODS 表。
2. 按词根识别字段，建议主题域、粒度、主键。
3. 套用 DWD 层脱敏、时间格式、空值策略：禁止下沉则去掉敏感字段；掩码/哈希/加密则转换；空值打回则约束主键与分区。
4. 展示规范问题（错误 / 警告 / 说明）。
5. 人工确认：主题域正确、粒度合适、敏感已处理。主题域把握不足时必须确认后才能过。
6. 存在规范**错误**时不能发布。
7. 具备「发布模型」权限的人审核通过后，生成已发布的 DWD 表。

## 5. DWD → DWS

1. 选择 DWD 与维度组合。
2. 当本层策略为「禁止下沉」时，不得把可识别个人身份的维度带入汇总表；违规则为错误，不能发布。
3. 产出汇总逻辑、预聚合参考 SQL、建议的质量规则。
4. 人工确认：汇总粒度合适、维度不含禁止下沉的信息、命名符合本层。
5. 同样须「发布模型」权限。

汇总表服务多组查询，**不是**一张表对应一个指标。指标落地在数据服务定义；物理可以是明细计算、汇总预聚合、应用表或查询时计算。

## 6. 表明细

展示字段、有效等级、不为空与默认值。  
DDL 区切换方言，注释规则与建表预览相同。  
可编辑、可删除（删除须确认；已被下游引用时产品上应提示，首期至少确认）。

## 7. 规范校验页

对项目内表跑命名与词根检查，只读。发布草案时已内嵌同一套检查。

## 8. 质量规则

生成草案时可附带建议规则（主键唯一、空值率、枚举等）。  
建模中心只保存建议，不在本中心执行巡检。执行在质量或开发能力中。

## 9. 与数据服务的边界

- 指标工厂、数据市场、查询网关不放在建模侧栏。
- 建模不把「注册指标」做成建表的必经步骤。
- 旧版数据服务入口若仍保留，与新数据服务并行，不在建模中心双开。

## 10. 权限（产品语义）

- 看表、草案、DDL：需要「读模型」
- 建改删表、发起生成：需要「写模型」
- 审核通过并发布草案：需要「发布模型」
- 规范错误未消除时，即使有发布权限也不可通过

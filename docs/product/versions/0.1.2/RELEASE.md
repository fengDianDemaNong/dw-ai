## 本版有什么

- **元数据库三选一**：未配置 `DB_URL` 时用嵌入式 **H2 文件库**；也可接 **MySQL** 或 **PostgreSQL**
- **演示数据默认不灌**：Flyway 只建表；试用执行 `./bin/seed.sh`
- **安装包拆分**：`app/` 业务 jar，`libs/` 第三方依赖；依赖未变时可只升级 `*-app.tar.gz`
- **使用说明**：安装、换库、灌演示数据、规范/建模走查、升级与备份
- **产品手册**：功能说明与界面截图，见 [docs/user/产品手册.md](../../../user/产品手册.md)

## 本版没有什么

- 不改控制台交互与 0.1.1 产品 spec
- 不交付开发中心、沉淀优化、数据服务
- 不新做可点击原型（仍用 `npm run proto -- 0.1.1`）

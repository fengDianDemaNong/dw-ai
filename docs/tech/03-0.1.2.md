## 1. 元数据库

| 项 | 规则 |
|---|---|
| 未设 `DB_URL` | `jdbc:h2:file:${DW_AI_HOME}/data/dwai`（`MODE=MySQL`，`AUTO_SERVER=TRUE`） |
| `jdbc:h2:` | H2；Flyway `classpath:db/migration/mysql`（与 MySQL 共用 DDL） |
| `jdbc:mysql:` | MySQL 8；`classpath:db/migration/mysql` |
| `jdbc:postgresql:` | PostgreSQL；`classpath:db/migration/postgresql` |
| `DB_TYPE` | 可选覆盖：`h2` / `mysql` / `postgresql` |

H2 默认账号 `sa` / 空密码。MySQL、PostgreSQL 须在 `conf/env.sh` 写 `DB_USER` / `DB_PASSWORD`。

实现：`MetaDb` + `MetaDbEnvironmentPostProcessor`（`addFirst` 注入 URL 与 `spring.flyway.locations`）。JSON 列用 `JsonbStringTypeHandler`：PostgreSQL 写 `jsonb`，其余 `setString`。密钥列保持 `byte[]` / `BLOB`。

Flyway **只含 DDL**，版本 `V1__schema.sql`。演示 `INSERT` 不进迁移。

## 2. 演示数据

| 文件 | 用途 |
|---|---|
| `classpath:db/seed/demo-mysql.sql` | H2 与 MySQL |
| `classpath:db/seed/demo-postgresql.sql` | PostgreSQL |

安装包复制到 `sql/`。`bin/seed.sh` → `com.dwai.platform.SeedMain`（不启 Web）。须 **先 `start.sh` 一次** 让 Flyway 建表。脚本按演示主键删除再插入，可重复执行。

---

## 3. 打包布局

```
bin/   start.sh stop.sh status.sh seed.sh
conf/  env.sh application.yml
app/   dw-ai-api.jar
libs/  第三方 *.jar ；.deps-hash
libs/web/
sql/   demo-*.sql
data/  H2（运行时）
logs/
```

启动：`java -cp app/dw-ai-api.jar:libs/* com.dwai.platform.DwaiApplication`  
`package.sh`：对 `services/api/pom.xml` 做 hash，写入 `release/.libs-cache`；hash 不变则不重拷依赖。另打 `dw-ai-${VERSION}-app.tar.gz`（无 `libs/*.jar`）。

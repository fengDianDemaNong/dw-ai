## 抽屉与接口对照（实现核对）

**用户抽屉 →** `PATCH /api/tenants/{id}/users/{userId}`（`PatchOrgUserReq`）

| 字段 | 请求字段 | 说明 |
|---|---|---|
| 显示名 | `displayName` | 随保存 |
| 用户名 | `username` | 全局唯一；冲突 409 |
| 角色 | `tenantRole` | `admin` / `member` |
| 状态 | `status` | `active` / `disabled`；不能停用自己 |
| 项目 | `memberships[]` | `{ projectId, role }` 全量同步 |
| 指定管理员 | `projectId` | 单独按钮，立即把该用户设为项目管理员 |
| 重置密码 | `password` | 单独按钮 |

**项目抽屉 →** `PATCH /api/projects/{id}`（`PatchProjectReq`）

名称 `name`、编码 `code`（租户内唯一）、说明 `description`、管理员 `owner`、状态 `status`。

行内已去掉：用户（停用、重置、指定管理员）；项目（进入、停用）。转让管理员、新增仍在页头。

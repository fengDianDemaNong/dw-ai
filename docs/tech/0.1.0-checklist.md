### 4.1 说明

- 控制台：授权码 + PKCE（`VITE_CASDOOR_ENDPOINT` / `VITE_CASDOOR_CLIENT_ID`）。
- API：`SECURITY_MODE=oidc` + `CASDOOR_ISSUER` 时用 Casdoor JWKS 校验 JWT。
- **本机未默认拉起 Casdoor 实例，也未验证官方 demo 可登录。** 配好再切 oidc。
- 无 Casdoor 配置时：`SECURITY_MODE=dev` + 登录页「开发登录」（张三 / 李四），接口形态与生产相同。
- 未配 `VITE_API_BASE`：仍走 localStorage 演示降级。

### 4.2 说明

Flyway：`tenants` / `projects` / `project_members` / `domains` / `layer_rules` / `data_grades` / `word_roots` / `warehouse_tables` / `table_columns` / `modeling_drafts` + 索引；种子为星河电商 / 交易数仓。

### 怎么启动

```bash
docker compose up -d postgres          # PostgreSQL 16 · 5432 · dwai/dwai/dwai
cd services/api && mvn spring-boot:run # API · 8080，Flyway 自动迁库
# 另开终端
npm install && npm run dev:api         # 控制台 · 5173（带 VITE_API_BASE）
# 或 cp ui/.env.example ui/.env.local && npm run dev

# 或仓库根一键容器：docker compose up -d --build → http://localhost/
# 或 ./package.sh 打安装包，解压后 ./bin/start.sh
```

登录页选开发登录「张三」→ 进入「交易数仓」。规范 / 表读写进 PG。

Casdoor（可选，未验证则不要设 `SECURITY_MODE=oidc`）：

```bash
# 自行 docker 跑 Casdoor，在控制台建 Application（开启 PKCE、Redirect = http://localhost:5173/auth/callback）
export SECURITY_MODE=oidc
export CASDOOR_ISSUER=http://127.0.0.1:8000
export CASDOOR_CLIENT_ID=<应用 client id>
export CASDOOR_ORG_MAP=built-in:t-xinghe
```

`.env.local` 同步 `VITE_CASDOOR_*`。官方 demo `https://door.casdoor.com` 同样要自己登记回调，仓库不假装已连通。

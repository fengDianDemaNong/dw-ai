# 0.1.5 技术对照：三模式与拆分

产品契约：[docs/product/versions/0.1.5/spec/06-runtime-modes.md](../product/versions/0.1.5/spec/06-runtime-modes.md)  
状态：实现中（同进程双挂）。路由真源 [06-0.1.5-routes.md](./06-0.1.5-routes.md)。拆独立安装包尚未做。

## 现在

| 位置 | 实际 |
|---|---|
| `dwai.deployMode` | 只有 `multi` / `standard` |
| `services/api` | 登录、租户、平台、规范、表、DS 客户端在一个 Boot |
| `Perms` | 写死 `admin/modeler/viewer` |
| `TenantFilter` | JWT + 本地用户表 + `X-Tenant-Id` |
| `ui` | 一个 SPA |
| `services/rules` | 已是独立 REST，无用户 |

## 目标增量

1. 每个模块进程增加 `dwai.run-mode=standalone|standard|multi`（组织平台无 standalone）。
2. 从 `services/api` 抽出组织包（可先同仓不同模块，再独立安装包）。
3. 仓建设 `multi`：启动 `POST {org}/internal/v1/registry/heartbeat`；写路径调 `{org}/internal/v1/authz/check`。  
   页面与接口 path 真源见 [06-0.1.5-routes.md](./06-0.1.5-routes.md)。
4. 仓建设 `standalone`：跳过 `AuthController` 与用户库；`Perms` 放行。
5. 前端按进程拆控制台；`runtime` 三种模式。
6. 项目创建：组织 `PUT {module}/internal/v1/projects/{id}`。

## 建议顺序

1. 产品窗口确认 06 文档（本目录不改行为）。
2. API 增加 `run-mode` 与 `/internal/v1/projects`，先不拆仓。路由按 [06-0.1.5-routes.md](./06-0.1.5-routes.md)。
3. 抽出组织 API，仓建设 `multi` 改远程鉴权。
4. 拆 `ui` 或按构建产物出两套静态资源。
5. DS / 引擎连接从全局配置迁到组织计算资源。

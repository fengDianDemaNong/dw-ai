## 阶段对照（实现顺序）

```
1 许可与授权 ─┬→ 2 提示词表与设置页（含接口对照）
              │         ↓
              │    3 代发组 system + 项目摘要
              │         ↓
              │    4 规范/建模页接 chat 与问答态
              │
              └→ 5 交互对齐（进租户 / 抽屉 / 项目状态）
                        ↓
                   6 知识库（V10 + 手册 + 导入）
                     （5.5 与 6.3 共用 projects.engines，先做 6.1）
```

0.1.1 / 0.1.2 已交付的身份、三套壳、模块、表版本不在上表重复。
